# Distill: מדאטה של חברה לתובנות ולאוטומציות

**פלטפורמת דאטה AI-native.** המערכת אוספת את הדאטה התפעולי של החברה ומוצאת מה השתנה, איפה התהליכים
נתקעים ומה אפשר להפוך לאוטומטי. סוכן Claude מסביר *למה* זה קרה, וכל תובנה הופכת לאוטומציה עובדת:
חוק ניטור, workflow שמיובא ל-**n8n** ו-**Agent Skill (SKILL.md)**. המערכת לומדת מהפידבק של המשתמשים
ומשתפרת עם הזמן.

## מה יש בפנים
- **איסוף:** קונקטורים ל-CSV/JSON, ל-REST API, למסדי נתונים SQL ול-webhook. סנכרון אינקרמנטלי עם cursor שנשמר.
- **הבנה:** זיהוי אוטומטי של סוג כל עמודה (כסף, זמן, אזור, מזהה תיק…) ושל סוג הטבלה.
- **ניתוח:** מגמות, פילוח שמוצא איזה סגמנט אחראי לשינוי (עם מבחן סטטיסטי), חריגות שמנוטרלות מעונתיות שבועית,
  ריכוזיות (פארטו) וקורלציות.
- **כריית תהליכים:** מפת תהליך מתוך לוג אירועים, צווארי בקבוק, לולאות חוזרות וציון פוטנציאל אוטומציה לכל שלב.
- **סוכן AI:** ‏Claude Opus 5.5 עם כלים. הוא מריץ שאילתות אגרגטיביות, חוקר סיבות שורש, עונה על שאלות
  חופשיות וכותב playbooks. המודל רואה רק אגרגציות, אף פעם לא שורות גולמיות.
- **אוטומציות:** כל תובנה מתורגמת לחוק, ל-n8n workflow ול-SKILL.md.
- **למידה עצמית:** בנדיט בייזיאני לכל סוג תובנה וספי חריגה שמתכווננים לפי פידבק.

## הרצה
ההוראות מופיעות ב-[README.md](README.md). בקצרה: `uvicorn distill.api:app` ב-backend ו-`npm run dev` ב-frontend.
אחר כך לוחצים על **Load demo company**.

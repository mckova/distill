# Distill

Distill קורא את הדאטה התפעולי של חברה ואומר מה השתנה, איפה העבודה נתקעת ומה שווה להפוך לאוטומטי. ואז הוא
עושה עם זה משהו: כל ממצא יכול להפוך לאוטומציית ניטור, ל-workflow שאפשר לייבא, ול-Agent Skill שמלמד כל סוכן AI
איך החברה הספציפית הזו עובדת.

סוכן Claude נמצא במרכז. הוא עונה על שאלות בעזרת שאילתות אגרגטיביות על הדאטה, סוקר את כל הממצאים ומכין
אוטומציות לאישור, זוכר מה הצוות מלמד אותו, וכותב מחדש את ה-playbooks. פידבק על ממצאים משנה את הדירוג שלהם
ואת רגישות הגלאים.

## מה יש בפנים
- **איסוף:** קונקטורים ל-CSV/JSON, ל-REST API, למסדי נתונים SQL ול-webhook. סנכרון אינקרמנטלי ומתוזמן.
- **הבנה:** זיהוי סוג כל עמודה ותפקיד הטבלה, ומילון עסקי לכל דאטהסט ש-Claude כותב.
- **איכות דאטה:** כפילויות, ערכים חסרים, טווחים לא הגיוניים ותאריכים עתידיים, בכל סנכרון.
- **ניתוח:** מגמות, הסגמנט שאחראי לשינוי, חריגות מנוטרלות עונתיות, ריכוזיות וקורלציות.
- **כריית תהליכים:** מפת תהליך מלוג אירועים, צווארי בקבוק, לולאות חוזרות ופוטנציאל אוטומציה לכל שלב.
- **אופטימיזציה:** כל הזדמנות מתומחרת בשעות צוות, בשעות המתנה או בהכנסה בסיכון לשבוע, עם סימולציה.
- **סקילס מהדאטה:** נוהל עבודה לכל תהליך ו-skill הקשר לכל דאטהסט, עם גרסאות, להורדה כ-zip.
- **הסוכן:** שיחה רב-שלבית עם 10 כלים, סקירת סוכן, וזיכרון חברה שמוזרק לכל משימה.
- **למידה:** דירוג שמתעדכן לפי פידבק, ספי חריגה שמתכווננים, וסיבות דחייה שהופכות לזיכרון.
